# Gloop Cup

Blob football, volleyball and cricket for up to three a side. Play online with friends or on one keyboard.

Play: https://rodneycumming.github.io/gloop-cup/

- Online: one person clicks **Host a game** and sends the invite link. Everyone else opens it and presses **Join**.
- Keys: A/D or ←/→ to move, W, ↑ or Space to jump.
- Online play connects browsers directly using [PeerJS](https://peerjs.com/). The host's browser runs the game, so the host should keep the tab in front.
